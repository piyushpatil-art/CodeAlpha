# CodeAlpha Machine Learning Internship

This repository contains projects completed as part of my **CodeAlpha Machine Learning Internship**. Each project explores a practical machine learning application, from data preprocessing and feature engineering to model training and evaluation.

## 📂 Projects

### Task 1: Credit Scoring Model
A machine learning project focused on credit risk classification using the German Credit dataset.

**Key areas covered:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation

📁 **Project folder:** [`Task_1`](./Task_1/)

---

### Task 3: Handwritten Character Recognition
A deep learning project that uses a Convolutional Neural Network (CNN) to recognize handwritten characters from image data.

**Key areas covered:**
- Image preprocessing
- Dataset preparation
- CNN model development using PyTorch
- Model training and evaluation

📁 **Project folder:** [`Task_3`](./Task_3/)

---

### Task 4: Diabetes Prediction Using Machine Learning
A binary classification project that predicts the likelihood of diabetes using medical attributes from the Pima Indians Diabetes dataset.

**Key areas covered:**
- Data analysis and visualization
- Missing or invalid value handling
- Data preprocessing and feature scaling
- Logistic Regression and XGBoost
- Cross-validation and model evaluation

📁 **Project folder:** [`Task_4`](./Task_4/)

**Note:** This project is for educational purposes only and is not intended for medical diagnosis.

---

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Deep Learning:** PyTorch, Torchvision
- **Development Environment:** Jupyter Notebook
